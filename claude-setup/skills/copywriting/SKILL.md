# Copywriting

## Outcome
Copy for one specific page or asset that a real prospect reads and acts on:
one clear promise, one obvious next step, in Dustin's voice.

## Before you write
Read what already exists — the live site, the current brochure, prior
campaigns, any brand file in this repo. Ask only what you genuinely cannot
find, and ask it in a single question. Don't run an intake interview.

You need three things: what page, who it's for, what the one action is. If two
are inferable, infer them and name the assumption.

## Hard boundaries
- Financial services copy is supervised. No performance claims, no guarantees,
  no "risk-free," no implied endorsement by Osaic or LRP.
- No invented statistics, testimonials, client names, or case studies. If a
  proof point would carry the section, write `[PROOF NEEDED: ___]` and move on.
- Don't promise outcomes an advisor can't control ("retire five years early").
  Sell the process, the relationship, and the clarity.
- Plain language for clients. If a term like "fiduciary" or "sequence risk"
  earns its place, define it in half a sentence.

## What good looks like
- **The headline stands alone.** If nothing else loaded, a prospect would still
  know what this is and whether it's for them.
- **Specific beats vague.** "A written plan you'll actually read" beats
  "comprehensive planning solutions."
- **Their words, not ours.** Mirror how clients describe the problem — "I don't
  know if I have enough," not "retirement income gap analysis."
- **One idea per section,** building down the page.
- **It sounds like Dustin** — direct, warm, a little wry. Not a brochure from
  2004, and not a LinkedIn growth thread.
- **Every CTA says what actually happens next.** Never "Learn More."

## Deliver
The copy itself, ready to paste. Then briefly: the thinking behind the
headline, and one alternative worth testing. Flag anything that needs
compliance review before it ships.
